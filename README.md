# ぷよぷよ (Puyo Puyo)

JavaScriptで実装されたぷよぷよパズルゲーム

## 遊び方

1. ブラウザで `index.html` を開く
2. キーボードで操作:
   - ←→キー: ぷよを左右に移動
   - ↓キー: ぷよを高速落下
   - Zキー: ぷよを回転

## ゲームルール

- 同じ色のぷよが4個以上繋がると消える
- ぷよが消えると上のぷよが落下し、連鎖が発生することがある
- ぷよが画面上部に到達するとゲームオーバー
- より多くの連鎖を作ってハイスコアを目指そう！

## ファイル構成

- `index.html` - ゲーム画面とスタイル
- `puyo.js` - ゲームロジックとメイン処理
- `README.md` - このファイル
